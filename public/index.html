Esta tela precisa do servidor do sistema

Os arquivos .html não funcionam abertos com dois cliques: sem o servidor o navegador não carrega o visual nem as funções.

Volte à pasta principal do sistema e abra o arquivo ABRA-ME.html. Ele mostra o passo a passo (são 3 passos).

Com o servidor rodando, esta tela abre pelo navegador no endereço http://localhost:3100 (demonstração).
